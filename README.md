# saeedkolivand/homebrew-tap

```sh
brew tap saeedkolivand/tap
brew trust --cask saeedkolivand/tap/claude-usage
brew install --cask claude-usage
```

| Cask | What |
|---|---|
| `claude-usage` | [Claude Code usage in the macOS menu bar and as a desktop widget](https://github.com/saeedkolivand/claude-usage-mac) |

## Why the extra `trust` step

Since [Homebrew 6.0](https://brew.sh/2026/06/11/homebrew-6.0.0/), third-party
taps must be trusted explicitly before Homebrew will evaluate their Ruby. That
followed a real incident where a compromised tap was used to ship malware, so
the prompt is doing its job — read the cask before you trust it.

`brew trust --cask saeedkolivand/tap/claude-usage` grants the narrowest useful
scope: this one cask. `brew trust saeedkolivand/tap` covers everything in the
tap, including anything added later.

## Why these live here and not in homebrew/cask

These builds are ad-hoc signed rather than notarized, and the main repository
[drops casks that fail Gatekeeper checks from 2026-09-01](https://github.com/orgs/Homebrew/discussions/6334).
Each cask clears the quarantine attribute in its `postflight`, since Homebrew is
also [removing the `--no-quarantine` flag](https://github.com/Homebrew/brew/issues/20755).

`Casks/claude-usage.rb` is generated by the release workflow in
[claude-usage-mac](https://github.com/saeedkolivand/claude-usage-mac); edit the
template there, not the file here.
